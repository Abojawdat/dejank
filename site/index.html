Three commands

Run them in any Flutter project after flutter pub get.

1dejank scan

Lists slow code with file and line, how much it hurts, and whether it can be fixed automatically. Exits with code 1, so it can guard CI.

2dejank fix

Rewrites the safe ones and shows the diff. Re-checks the fixed code first and skips any fix that would add an error. --dry-run to preview.

3dejank measure

Runs your integration test with dejank_meter (add it as a dev dependency), counts widget rebuilds and frame times, and compares them with the last run.

The rules

Only performance, only rules that matter. A wrong warning is treated as a bug.
